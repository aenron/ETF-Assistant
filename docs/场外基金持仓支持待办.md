# 场外基金持仓支持待办

## 目标

让场外基金可以进入持仓组合，同时投资建议、定投灯、趋势信号按净值型资产口径计算，避免复用 ETF 的场内交易指标导致误判。

## 实施清单

- [x] 增加持仓资产类型字段 `asset_type`，默认 `etf`，支持 `otc_fund`。
- [x] 后端接口透传 `asset_type`，新增/编辑持仓时可选择 ETF 或场外基金。
- [x] 行情展示按类型分流：ETF 展示价格/实时行情，场外基金展示单位净值/净值日期。
- [x] 场外基金市值与盈亏使用单位净值计算，继续纳入组合汇总和再平衡。
- [x] 定投灯按资产类型分流：ETF 使用现有估值/趋势规则，场外基金使用净值趋势、回撤、目标仓位和可选估值映射。
- [x] 趋势信号按资产类型分流：场外基金不使用成交量、IOPV、溢价等场内指标。
- [x] 投资建议 prompt 按资产类型描述数据语义，场外基金强调净值、回撤、基金暴露和长期配置。
- [x] 前端列表和表单展示资产类型，并隐藏或弱化场外基金不适用的 ETF 专属指标。
- [x] 补充后端单元测试，覆盖资产类型默认值、场外基金净值口径、信号分流。

## 最小落地路径

1. 增加 `asset_type`，旧持仓默认 ETF。
2. 场外基金复用现有净值行情兜底计算市值/盈亏。
3. 场外基金趋势信号使用净值 MA20/MA60、回撤、近阶段收益。
4. 场外基金定投灯先使用趋势信号结果和目标仓位，估值映射存在时再叠加估值。
5. 前端把标签、列名和说明改成资产类型敏感展示。
