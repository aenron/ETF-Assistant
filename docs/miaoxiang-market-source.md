# 东方财富妙想行情源

后端通过官方 `mx-data` Skill 使用的数据接口获取公开行情：
`POST https://mkapi2.dfcfs.com/finskillshub/api/claw/query`，请求头 `apikey`，请求体 `{"toolQuery": "查询条件"}`。
适配器使用已有的 httpx，Docker 不需要安装 Codex、Skills 或额外 Python 依赖。

## 配置

在已被 Git 忽略的 `backend/.env` 设置 `MX_APIKEY`；`MX_ENABLED=false` 可关闭。
Docker Compose 已通过 `env_file` 将该文件传给后端；更新配置后需要重建容器。
密钥不进入镜像，`.dockerignore` 已排除 `.env`。示例和可调缓存、间隔、超时配置见 `backend/.env.example`。

## 能力与优先级

- 报价：现有 沪深交易所、同花顺行业指数、新浪、腾讯之后，未取得报价时使用妙想最近完成交易日的场内价格。
- 日线：现有 沪深交易所和已配置的 Tushare 之后，新浪估算成交额之前；要求完整开高低收、成交量和实际成交额，支持 1–250 个交易日。
- 场外基金、同花顺行业代码等无法确定沪深证券代码的品种仍使用既有数据源。
- 不采用基金净值增长率作为场内涨跌幅，报价涨跌幅用场内收盘价和昨收计算。
- 批量报价可能把成交额改为“成交额（含大宗交易）”并以多证券矩阵返回；该不同口径不会填入报价成交额，缺失时保留为空。已验证的完整日线使用标准 `AMOUNT` 数据。
- 数据日期保留为实际交易日；日线报价时间为该日 15:00，不标记为实时快照。没有足够日期、字段或不匹配证券代码的数据会被拒绝，继续回退。
- 默认报价缓存 300 秒，历史查询缓存 7200 秒；请求串行，最小间隔 3 秒。当前使用单进程后端，缓存、限流和冷却均为进程内状态。
- 频率限制、网络异常触发 60 秒冷却；额度或认证错误触发 1 小时冷却，保护现有行情流程。多进程部署需将限流和缓存改为共享状态。
- 分钟线、IOPV 和溢价率暂沿用既有来源。

## 验证

`python -m unittest tests.test_miaoxiang_service` 验证净值和价格口径、数值单位、日期与证券匹配、嵌套业务错误、请求去重、冷却以及行情源回退顺序。

2026-10-11 接入前实测：510300.SH 返回开高低收、昨收、成交量及成交额；159915.SZ 返回收盘价、成交量和成交额；510300.SH 的最近 60 日查询返回 61 个交易日。
