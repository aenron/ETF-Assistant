# 数据源能力清单

本文档记录 ETF Assistant 当前和候选行情数据源的能力边界。后续新增数据源或调整行情链路时，先对照这里确认字段覆盖、稳定性和适合接入的位置。

## 当前数据需求

| 场景 | 必需字段 | 说明 |
|---|---|---|
| 持仓列表实时行情 | 最新价、涨跌幅、成交额、成交量、刷新时间 | 用于现价、市值、今日涨跌、行情时间展示 |
| 详情页历史 K 线 | 日期、开盘、收盘、最高、最低、成交量、成交额、涨跌幅 | 用于图表、技术指标、交易指示 |
| 趋势交易指示 | 最近 60 日 K 线、最近 6 日成交额、基准指数涨跌幅 | 前端实时计算，后端负责补齐数据 |
| 定投红绿灯 | 最新行情、历史 K 线、估值/趋势因子 | 后端定时计算并持久化 |
| 基准指数 | 沪深 300、中证 A500 的实时行情和历史 K 线 | 用于相对强弱判断 |

## 数据源概览

| 数据源 | 配置 | 当前用途 | 优先级建议 | 主要优势 | 主要限制 |
|---|---|---|---|---|---|
| 智兔数服 | `ZHITU_TOKEN` | ETF 实时行情、指数历史 K 线 | 实时 ETF 与指数历史优先 | 实时 ETF 成交额完整，指数历史字段完整 | ETF 历史 K 线实测无数据 |
| QMT Agent | `QMT_AGENT_BASE_URL`, `QMT_AGENT_TOKEN` | 实时行情、历史 K 线 | 本地可用时优先 | 本地行情源，可控性强 | 依赖本地 QMT 服务可用性 |
| AkShare | 无 | ETF/股票/基金多类历史与实时补充 | 公共源主力补充 | 覆盖广、无需 token | 容易受上游网页/API 变化影响 |
| 东方财富 | 无 | 实时行情、历史 K 线兜底 | ETF/股票历史优先兜底 | 字段含成交额，适合历史 K 线 | 网络偶发断开，部分代码需 secid 匹配 |
| 新浪财经 | 无 | 历史 K 线最后兜底 | 最后兜底 | 可拿到价格和成交量，稳定性尚可 | 通常无成交额，需要后端估算 |
| Tushare | `TUSHARE_TOKEN` | 实时/历史补充 | 有 token 时补充 | 日线数据规范 | 免费/权限限制，ETF 覆盖需按 token 权限确认 |
| 同花顺行业指数 | 无 | 88xxxx 行业指数行情 | 行业指数优先 | 能覆盖行业指数场景 | 不是 ETF 数据源 |
| Redis/DB 缓存 | `REDIS_URL`, 数据库 | 行情缓存、K 线缓存 | 读取优先 | 降低外部请求，提高页面速度 | 需要刷新任务保证新鲜度和成交额完整性 |

## 智兔数服

配置项：

```env
ZHITU_TOKEN=
```

已接入位置：

- `MarketService.refresh_quotes`：优先调用基金实时行情。
- `MarketService.get_history_kline`：对指数代码优先调用智兔指数历史 K 线。
- 统一来源日志：`source=zhitu_fund_real`、`source=zhitu_index_history`。

### 已验证接口

| 接口 | 示例 | 结果 | 可用字段 |
|---|---|---|---|
| ETF 实时行情 | `/fund/real/ssjy/511380` | 可用 | `p`, `pc`, `o`, `h`, `l`, `yc`, `cje`, `v`, `pv`, `t` |
| ETF 列表 | `/fund/list/etf` | 可用 | `dm`, `mc`, `jys` |
| 指数实时行情 | `/hz/real/ssjy/000300.SH` | 可用 | `p`, `pc`, `o`, `h`, `l`, `yc`, `cje`, `v`, `pv`, `t` |
| 指数历史 K 线 | `/hz/history/fsjy/000300.SH/d` | 可用 | `t`, `o`, `h`, `l`, `c`, `v`, `a`, `pc`, `sf` |
| 普通 A 股历史 K 线 | `/hs/history/000001.SZ/d/n` | 可用 | `t`, `o`, `h`, `l`, `c`, `v`, `a`, `pc`, `sf` |
| ETF 历史 K 线 | `/hs/history/511380.SH/d/n` | 不可用 | 返回 `数据不存在` |

### 字段映射

ETF 实时行情：

| 智兔字段 | 系统字段 | 说明 |
|---|---|---|
| `p` | `price` | 最新价 |
| `pc` | `change_pct` | 涨跌幅 |
| `o` | `open_price` | 开盘价 |
| `h` | `high_price` | 最高价 |
| `l` | `low_price` | 最低价 |
| `cje` | `amount` | 成交额 |
| `pv` 优先，`v` 兜底 | `volume` | 成交量。实测 `pv` 更接近原始成交量 |
| `t` | `refreshed_at` | 更新时间 |

指数历史 K 线：

| 智兔字段 | 系统字段 | 说明 |
|---|---|---|
| `t` | `trade_date` | 交易日期 |
| `o` | `open_price` | 开盘价 |
| `h` | `high_price` | 最高价 |
| `l` | `low_price` | 最低价 |
| `c` | `close_price` | 收盘价 |
| `v` | `volume` | 成交量 |
| `a` | `amount` | 成交额 |
| `pc` | 用于计算 `change_pct` | 前收盘价 |

### 接入结论

智兔适合：

- ETF 盘中/收盘实时行情轻刷新。
- 当日成交额补充。
- 沪深 300、中证 A500 等指数历史 K 线和成交额。
- 普通 A 股历史行情补充。

智兔暂不适合：

- ETF 历史日 K 线。
- ETF 过去 5 日/60 日真实历史成交额的唯一来源。

## QMT Agent

配置项：

```env
QMT_AGENT_BASE_URL=
QMT_AGENT_TOKEN=
```

当前用途：

- 实时行情：`_fetch_from_qmt_agent`。
- 历史 K 线：`_fetch_history_kline_qmt_agent`。

适合场景：

- 本地 QMT 可用时，作为高优先级数据源。
- ETF 历史 K 线和成交额优先来源。

注意事项：

- 依赖本地服务可达性。
- 需要观察返回字段是否持续包含 `amount`。

## AkShare

配置项：无。

当前用途：

- ETF 实时行情列表。
- ETF 历史 K 线。
- A 股历史 K 线。
- 场外基金净值走势兜底。

适合场景：

- 无 token 环境的基础行情源。
- 多品种覆盖补充。

注意事项：

- 依赖第三方网页/API，上游不稳定时会失败。
- 部分数据源字段名可能变化，解析时需要兼容。

## 东方财富

配置项：无。

当前用途：

- ETF 批量实时行情。
- 单证券实时行情兜底。
- 通用历史 K 线兜底。

适合场景：

- ETF/股票历史 K 线，字段含成交额。
- AkShare 失败时的直接 API 兜底。

注意事项：

- `secid` 需要按市场尝试。
- 实测偶发 `Server disconnected without sending a response`。

## 新浪财经

配置项：无。

当前用途：

- 历史 K 线最后兜底。

适合场景：

- 其它历史源失败时补价格和成交量。

注意事项：

- 通常不返回成交额。
- 当前后端会在缺成交额时按 `成交量 * 日均价` 估算，来源日志标记为 `sina_history_estimated_amount`。
- 估算成交额只用于避免交易指示长期待数据，不等同于交易所真实成交额。

## Tushare

配置项：

```env
TUSHARE_TOKEN=
```

当前用途：

- 实时行情/日线补充。

适合场景：

- 有 token 且权限覆盖时，作为标准化数据补充。

注意事项：

- 权限与频率受 token 套餐限制。
- ETF 覆盖需要按实际 token 权限验证。

## 同花顺行业指数

配置项：无。

当前用途：

- `88xxxx` 行业指数历史行情和最近行情。

适合场景：

- 行业指数/行业基本面相关展示。

注意事项：

- 不是 ETF 历史 K 线来源。
- 不适合替代持仓 ETF 数据。

## 缓存与持久化

| 层级 | 用途 | 注意事项 |
|---|---|---|
| Redis quote cache | 实时行情缓存 | 页面读取优先，带 `refreshed_at` |
| Redis K 线 cache | 短期 K 线缓存 | 命中时需检查最新日期和成交额 |
| longer Redis K 线 cache | 更长周期 K 线复用 | 用于 120/140 日等缓存裁剪到 60 日 |
| `market_daily` DB | 持久化 K 线 | 当前保存并更新 `amount` 字段 |

## 当前来源日志格式

实时行情：

```text
[MarketService] 数据来源 quote code=511380 source=zhitu_fund_real price=13.9870 change_pct=0.3876 amount=7937488400.00 volume=568827149
```

历史 K 线：

```text
[MarketService] 数据来源 kline code=000300 source=zhitu_index_history rows=60 latest=2026-06-24 close=4943.0200 amount=964945849978.70 amount_rate=100.0%
```

常见 `source`：

| source | 含义 |
|---|---|
| `zhitu_fund_real` | 智兔 ETF 实时行情 |
| `zhitu_index_history` | 智兔指数历史 K 线 |
| `qmt_agent_history` | QMT Agent 历史 K 线 |
| `akshare_etf_history` | AkShare ETF 历史 K 线 |
| `eastmoney_history` | 东方财富历史 K 线 |
| `sina_history_estimated_amount` | 新浪历史 K 线，成交额由后端估算 |
| `redis_cache` | Redis 短期缓存 |
| `redis_longer_cache` | Redis 长周期缓存裁剪 |
| `database_cache` | `market_daily` 持久缓存 |

## 后续新增数据源评估清单

新增数据源前至少验证：

1. ETF 实时行情是否包含最新价、涨跌幅、成交额、成交量、更新时间。
2. ETF 历史日 K 是否包含 OHLC、成交量、成交额、交易日期。
3. 指数历史日 K 是否支持沪深 300 和中证 A500。
4. 是否支持按最近 N 条或开始/结束日期查询。
5. 更新时点是否满足 10:35、14:35、15:02 的重刷新任务。
6. 请求频率是否能覆盖持仓数量和页面并发。
7. 失败时返回格式是否稳定，便于降级。
8. 字段单位是否明确，尤其是成交量和成交额。
9. 是否允许生产用途，token 是否需要保密。
10. 接入后必须添加统一 `数据来源` 日志。
